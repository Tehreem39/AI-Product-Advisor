# AI-Product-Advisor
A Python-based rule-driven AI expert system for product recommendations.

## Project Overview
AI Product Advisor is a Python-based expert system that provides product recommendations using predefined rules and a knowledge base.
The system uses user-provided information to identify suitable product recommendations.

## Features
- Rule-based recommendation system.
- Knowledge base containing product information.
- User interaction through a console interface.
- Product recommendations based on predefined conditions.
- Certainty factor (if implemented in the project).

## Technologies Used
- Python
- Rule-Based Expert System
- Artificial Intelligence Concepts

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file:
   software_Recommendation.py
